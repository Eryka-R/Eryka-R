## About

I studied **Computer Engineering** at the **University of Zaragoza** and
continued with a Master's Degree in **Robotics, Graphics and Computer Vision**.

Most repositories in this profile were developed as university projects,
laboratory assignments, or learning projects. Together, they cover machine
learning, medical image analysis, computer vision, robotics, SLAM, virtual
reality, rendering, performance analysis, Android development, full-stack web
development, and game development.
